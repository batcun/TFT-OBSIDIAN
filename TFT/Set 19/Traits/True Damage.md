# True Damage

**Band** · Breakpoints: **3 / 5 / 7 (+ Prismatic)** · Back to [[Set 19 Summary]] · [[Traits Overview]]

## What it does
- Earn **Bling** and convert it to loot. **A-Side** rewards win streaks with bonus true damage; **B-Side** gives Bling on loss streaks.
- You can flip sides mid-game. B-Side only counts losses made while it's active; switching back to A-Side keeps that loss streak.
- Unlocks: [[Unlocks#Yasuo|Yasuo]], [[Unlocks#Akali (True Damage)|True Damage Akali]] (only if K/DA Akali isn't unlocked). Reaches a Prismatic tier.
